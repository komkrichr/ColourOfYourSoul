# Colour of Your Soul

A bespoke palette generator inspired by your zodiac sign and personal colour analysis. High-fashion editorial design in the spirit of *The Cerulean Issue*.

## What it does

Enter your name, date of birth, and personal colour season — receive:

- Your zodiac sign with element & traits
- A personalised 8-colour palette (zodiac × season)
- A signature **Power Colour** mapped to your element/season combination
- Three editorial looks (Daytime · Evening · Statement) tailored to your element
- Three styling techniques (Power Colour placement · the 70/20/10 rule · texture mixing)

## Run it

It's a single static HTML file — no build, no server.

```bash
open index.html
```

Or double-click `index.html`. Works in any modern browser.

Live demo: https://komkrichr.github.io/ColourOfYourSoul/ (enable GitHub Pages in repo settings)

## Tech

Plain HTML + CSS + JavaScript. Fonts via Google Fonts (Playfair Display, Inter, Sarabun).
