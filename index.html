Find Your Season

เช็ค Personal Colour ของตัวเอง

เทคนิคเช็คสำหรับคนไทย — 3 ขั้นตอน
  1. ดูเส้นเลือดที่ข้อมือ ในแสงธรรมชาติ
    • เห็นเขียว = โทนอุ่น (Spring / Autumn)
    • เห็นฟ้า / ม่วง = โทนเย็น (Summer / Winter)
  2. เทสต์ทอง vs เงิน เอากระดาษทองและกระดาษเงินส่องใกล้ใบหน้า
    • ทอง เด่น ผิวสว่างขึ้น → โทนอุ่น
    • เงิน เด่น ผิวสะอาดขึ้น → โทนเย็น
  3. เช็ค contrast ระหว่างสีผม / ตา / ผิว
    • คอนทราสต์ชัด (ผิวขาวผมดำสนิท) → Bright (Spring / Winter)
    • คอนทราสต์นุ่ม กลมกลืน → Soft (Summer / Autumn)
Quick Match — ลักษณะคนไทยทั่วไป
ผิวขาวอมเหลือง · ใส่ทองเข้าSpring

ผิวสองสี / แทน · เอิร์ทโทนเข้าAutumn
ผิวขาวเย็น · ดำ-แดงสดเข้าWinter
